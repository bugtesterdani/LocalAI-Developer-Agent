# M4-Beispiel (Python): Rechner

Kleines Python-Paket für die Ende-zu-Ende-Prüfung von M4: Patch anwenden, `pytest` in der Offline-VM,
Reparatur durch den Debugger. Braucht nur pytest (in der python-Toolchain enthalten).

Beispielziel für den Chat: „Füge teilen(a, b) hinzu. Teilen durch 0 soll einen ValueError mit deutscher
Meldung auslösen. Mit Tests.“
